Installera AQC konsult-hantering

En enkel steg-för-steg-guide för Mac. Installationen tar normalt bara några minuter.

Det här behöver du
En Mac med ChatGPT desktop-appen och internetanslutning. Du behöver inte logga in på GitHub eftersom plugin-repot är offentligt.

Installation på Mac

1Öppna Terminal

Tryck på Command + mellanslag. Skriv Terminal och tryck på Enter. Ett fönster med text öppnas.

2Installera Codex

Kopiera hela raden nedan, klistra in den i Terminal och tryck på Enter: 

npm install -g @openai/codex@latest

Vänta tills kommandot är färdigt. Om Macen frågar efter ditt lösenord skriver du lösenordet du använder när du loggar in på Macen. Tecknen syns inte medan du skriver; det är normalt.

Om Terminal säger att kommandot npm saknas, kontakta er administratör eller support innan du fortsätter.

3Lägg till AQC:s plugin-marknadsplats

Kopiera raden nedan, klistra in den i Terminal och tryck på Enter:

codex plugin marketplace add NiklasAbrahamsson/aqc-chatgpt-plugins

Detta lägger till den offentliga marknadsplatsen AQC Plugins på din Mac.

4Installera pluginet

Kopiera raden nedan, klistra in den i Terminal och tryck på Enter:

codex plugin add aqc-konsult-hantering --marketplace aqc-plugins

Pluginet AQC konsult-hantering installeras nu lokalt på din Mac.

5Starta om ChatGPT

Stäng ChatGPT desktop-appen helt och öppna den igen. Öppna sedan plugin-menyn och kontrollera att AQC konsult-hantering finns installerat under AQC Plugins.

Kontrollera installationen

Om du vill kontrollera installationen i Terminal kan du köra:

codex plugin marketplace list
codex plugin list

Den första raden ska visa aqc-plugins. Den andra ska visa aqc-konsult-hantering.

Om pluginet ska användas i webbläsaren

En installation på Macen gör inte automatiskt pluginet tillgängligt i ChatGPT på webben.

För webbanvändning behöver en administratör i ett Business- eller Enterprise-workspace publicera pluginet:

  1. Öppna ChatGPT och gå till workspace-områdets plugin-sektion.
  2. Välj Personal.
  3. Öppna menyn med tre punkter för AQC konsult-hantering.
  4. Välj Publish.

Efter publicering kan medlemmar i workspacet använda pluginet på webben och på andra enheter. Menynamnen kan ändras när ChatGPT uppdateras.

Viktigt: För ett personligt Plus- eller Pro-konto räcker inte GitHub-repot för att få pluginet i webbläsaren. Då krävs antingen publicering i ett Business- eller Enterprise-workspace, eller att pluginet skickas in till OpenAI:s publika Plugins Directory för granskning.

Uppdateringar

När en ny version har publicerats, öppna Terminal och kör:

codex plugin marketplace upgrade aqc-plugins

Starta sedan om ChatGPT desktop-appen.
